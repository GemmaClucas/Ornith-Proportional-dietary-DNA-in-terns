Code for analysing the metabarcoding data from the publication "Proportional dietary DNA as a quantitative metric to monitor the diet composition of piscivorous terns" published in Ornithology.  

Qiime2 code can be found in the MiFish_Qiime2_commands.md file and the metadat for the samples is found in mdat.txt. The raw seqeuncing data can be downloaded from the Sequence Read Archive: https://submit.ncbi.nlm.nih.gov/subs/sra/SUB16390342/overview
